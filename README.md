# limits-panel

Мод для Claude Code: строка над полем ввода с расходом лимитов.

- шкалы 5-часового и недельного лимитов с процентом и временем до сброса (`⟳2д 3ч`);
- заполнение контекстного окна;
- стоимость сессии.

Цвета берутся из темы приложения, поэтому панель читается и в светлой, и в тёмной теме.
Лимиты доступны только на подписке; без неё показывается «лимиты недоступны».

## Подключение

Склонируйте репозиторий и запускайте Claude Code с указанием папки мода:

```bash
claude --plugin-dir /путь/к/limits-panel
```

или задайте переменную окружения `CLAUDE_CODE_PLUGIN_DIRS` и перезапустите приложение.
